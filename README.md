# Treinamento em Java

## Exercícios

### Exercício 1: Calculadora Simples

**Conceitos:** Variáveis, tipos primitivos, operadores, if

**Descrição:** 
Crie um método `calcular(int a, int b, String operador)` que retorna o resultado de uma operação: soma, subtração, multiplicação ou divisão.

**Teste unitário:**
- `calcular(10, 5, "+")` → 15
- `calcular(10, 5, "-")` → 5
- `calcular(10, 0, "/")` → lança `ArithmeticException`
